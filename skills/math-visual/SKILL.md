# MathVisual

先确定数学对象、定义域、参数、坐标、单位和想观察的机制，再选静态图、交互、动画或可复现绘图代码。用户只求理解时可用准确示意；要可分享图件时应实际渲染并检查文件。没有绘图环境时交付可运行源码与明确的未渲染状态。

二维/三维投影、网格、采样、数值积分、尺度截断和颜色映射都须标注。交互只在宿主真实支持参数调节、旋转或导出时称可用。图像与有限轨迹不能代替证明，PDE 演化图还要交代方程、边界与初始条件。保留源码、参数和产物路径以供复现。
