# MathPath

明确目标、现有基础、可投入时间和需要达到的证明或计算能力。从 `knowledge/learning-graph.json` 的示例节点或用户课程材料建立依赖路径；随包图只是起点，不能冒充完整 MSC2020 图谱。为每阶段列核心定义、定理、典型任务、可验证完成标准与下一节点。教材建议核对书目信息，未核查时标记为建议。

进度只依据用户实际完成的题目或记录，不从对话次数推断掌握程度。需要持久化时在用户指定位置保存节点 ID、状态、日期和证据；没有写入则明确这是本次建议路线。
