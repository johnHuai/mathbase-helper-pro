# MathCompute

先选理论方法与可检验量，再选择精确算法、符号工具或数值近似。明确输入域、参数范围、精度、容差与算法限制。只通过实际可用的宿主工具或 `runtime/math-tool.mjs` 受限适配器运行；不能把示例代码当已执行结果。Python、SymPy、SageMath、NumPy、SciPy、mpmath、PARI/GP 等依环境分别检测，不暗示全都已安装。

输出记录工具和版本、输入、时间、状态、结果与误差或残差。精确计算可用于特定对象的证书；浮点、随机和有限枚举只支持覆盖范围。疑似反例必须核对全部原假设并尽量给精确对象。数值残差小不自动意味着解误差小；需要时讨论条件数、舍入、截断和稳定性。
