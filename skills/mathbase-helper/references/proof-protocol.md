# Proof Protocol v2

1. **核对题意**：写出对象、定义域、全部量词、假设与目标；歧义可能改变结论时先指出。
2. **规划**：识别核心困难，列出候选定理及其适用条件，选择证明路线并解释关键构造的动机。
3. **构建**：逐步给出必要引理和推导；说明条件的实际使用，处理特殊参数与边界情形。
4. **独立审查**：重新检查量词、定理条件、遗漏假设、循环依赖、退化情况；尝试构造反例。不要把重述原证明当作审查。
5. **工具验证**：只在适用且工具可用时运行。记录原始命题与形式化命题的对应情况；计算只支持其覆盖的范围。
6. **呈现**：先给结论，再给足关键依据；必要时列出未完成的证明义务。不要为了模板重复题意。

对错误命题，给出反例并指出可以成立的附加条件。无法补齐关键引理时，将证明标记为草稿。
