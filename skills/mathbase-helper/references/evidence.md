# 证据状态

状态按证据类型记录，不视为单一线性等级。

| 状态 | 使用条件 |
| --- | --- |
| Unverified | 结论或关键步骤尚未核查。 |
| Draft Proof | 已有候选证明，仍有待检查的义务。 |
| Reviewed Proof | 已逐项逻辑审查，说明审查范围与残留缺口。 |
| Computation Supported | 真实计算提供有限范围或特定实例的支持，附版本、输入、精度和误差。 |
| Formally Checked | 真实证明检查器通过，且核对命题对应、占位符、额外公理与依赖范围。 |

任何工具记录都应包含运行时间、名称与版本、输入或文件哈希、退出状态、结果和日志位置（若有）。未运行时写“未运行”，不能伪造时间或日志。
