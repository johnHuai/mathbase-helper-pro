# MathWrite

按论文、讲义、综述、研究笔记或审稿回复确定文体。先核对数学内容：定义、假设、量词、证明义务和引用支持，再处理结构、术语、编号、交叉引用与排版。润色不得悄悄改变命题强度；未证结论保留可见的待证标记。参考文献不凭记忆捏造 DOI、卷页或链接，BibTeX 字段按实际来源填写。

默认兼容 Obsidian Markdown 与 LaTeX 数学公式。生成 `.tex` 或 `.md` 文件时使用用户指定位置；若实际编译，记录引擎和错误，未编译则说明。投稿信、审稿回复只声明作者确认过且实际完成的修改。可参考 `templates/` 的通用骨架，不称其为期刊官方模板。
