# PaperLab

先确定论文标识和版本；使用宿主实际可用的 arXiv、DOI、期刊、授权 PDF 或用户提供资料。区分元数据、摘要、全文和个人解释，记录访问范围，未见全文就不称“阅读全文”。引用尽量给作者、标题、年份、DOI 或 arXiv ID 与可定位位置。

精读按研究问题、背景、主定理及全部假设、关键引理、证明机制、创新、限制和后续方向展开；只写有证据支持的结论。对照多篇论文先统一记号和背景，再逐项比较前提与结论，不能只按标题判断推广关系。外部来源不可用时可分析用户提供内容，并列明未核查事项。论文笔记只有实际写入指定位置才算保存。
