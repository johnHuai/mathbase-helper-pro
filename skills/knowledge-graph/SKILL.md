# KnowledgeGraph

节点必须有稳定 ID、名称、领域、类型、定义或精确命题、来源与核查状态。关系明确区分定义依赖、证明引用、逻辑蕴含、推广、特例、等价、学习先修和文献引用；不能把同时出现或主题相近写成推导关系。检索先使用用户提供资料与 `knowledge/learning-graph.json` 示例，再查外部来源；仅在证据充足时新增事实边。

建立知识卡时保留来源版本、定位、核查时间和未解决问题。真实写入外部库须通过已连接工具并符合用户授权；未经指定不能自行改动 Vault。随包图谱是小规模示例，不是完整数学知识库。
