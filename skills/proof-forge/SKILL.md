# ProofForge

遵循总入口的 Proof Protocol v2。先判定命题是否可能错误；主动检查最小、零、空集、退化和边界情形。明确量词、底域、正则性和拓扑假设。对可能使用的定理逐项对照条件。选择证明策略时解释关键构造或变换为何有用。

写出完整必要推导。若某引理无法证明或文献来源未核实，明确留下证明义务，不用“显然”隐藏缺口。候选证明完成后调用 `proof-audit` 的审查流程；若无法完成审查，只能标记 Draft Proof。用户只要提示时给最小有用提示。
