# 数学质量与验收

静态检查覆盖包名、版本、技能目录、入口路由、领域元数据、JSON 结构、私密路径和密钥模式。运行时边界测试检查无效操作、越界表达式与项目外 Lean 文件被拒绝。运行：`node tests/validate.mjs`、`node tests/runtime.test.mjs`。

数学回答验收用代表题目复核，不把技能存在等同于正确证明：控制收敛条件、Jordan 块重数、紧致性反例、PDE 能量估计、无条件极限交换、量词倒置、循环证明与形式化 `sorry`。每个案例记录原命题、期望识别的义务、实际答案和审查结论；未运行模型评测时不得写“通过”。

计算证据记录时间、工具与版本、输入、精度、误差、退出状态和日志；有限实验只支持所覆盖对象。文献记录版本与访问范围。论文或开放问题状态需要可追溯来源。发布前检查所有包文件，公开仓库不包含账号回执、用户笔记、密钥或本地路径。
